## 2024-09-13 - Safely Disabling Tkinter Controls During Async Tasks
**Learning:** In TalkClip's Tkinter UI, users could change configurations (like the model or refinement checkbox) while asynchronous tasks (like audio recording and background processing) were actively running, which could cause mid-task configuration errors. Modifying Tkinter widgets from a background thread directly can lead to thread-safety issues.
**Action:** When implementing UX disabled states for async tasks in Tkinter, wrap widget state modifications (`widget.config(state=tk.DISABLED)` and `tk.NORMAL`) in helper methods and explicitly route them through the main thread using `self.root.after(0, ...)`. Always restore the state in a `finally` block to ensure controls are re-enabled even if an exception occurs.
