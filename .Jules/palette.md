## 2024-11-20 - Tkinter UI Thread Safety and State Locks
**Learning:** In desktop Python Tkinter apps like TalkClip, UI controls (like radio buttons for model selection) need to be explicitly disabled (`state=tk.DISABLED`) during asynchronous tasks (like background audio recording or processing) to prevent users from changing configurations mid-task. Furthermore, modifications triggered by background threads must be safely delegated back to the main thread using `self.root.after(...)` to ensure thread safety and avoid UI freezes.
**Action:** When implementing background processing in Tkinter apps, always wrap state transitions in helper methods and schedule their execution on the main thread via `after(0, ...)`. Ensure a `finally` block unlocks the UI (`state=tk.NORMAL`).
